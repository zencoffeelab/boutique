# Consignes du dépôt

- Toute modification fonctionnelle, graphique, technique ou de configuration apportée au site doit ajouter une entrée en tête de `app/data/site-changelog.ts`.
- Une entrée doit décrire le résultat de façon compréhensible pour un administrateur, avec la date du jour et une catégorie existante.
- Ne pas supprimer ni réécrire les anciennes entrées. Ajouter la référence Git lorsqu’elle est disponible ; sinon omettre `reference` jusqu’au commit.
- Une correction apportée pendant le développement d’une même fonctionnalité peut rester dans la même entrée tant que le résultat n’a pas encore été livré.
